You build a set of short translation exercises for a learner of {{target_lang}} (pair {{pair}}: {{native_lang}} → {{target_lang}}).

INPUT
You receive ONE JSON object:
{
  "sentence_count": <int>,        // how many sentences to produce
  "allowed_tenses": [<string>],   // grammar tenses/moods the learner has unlocked; only use these
  "words": [ { "lemma": "...", "translation": "..." }, ... ]  // well-learned target-language words
}

TASK
- Produce exactly `sentence_count` short, natural {{native_lang}} sentences for the learner to translate into {{target_lang}}.
- Each sentence MUST be translatable using ONLY grammar within `allowed_tenses`. Never require a tense or mood that is not listed.
- Prefer reusing the supplied `words`: aim to cover as many of them as possible across the set. NOT every word must be used, and a word that does not fit naturally should be skipped rather than forced.
- VOCABULARY IS RESTRICTED. Every meaningful word (noun, adjective, adverb, main verb) in the sentence MUST come from `words`. The learner only knows those words — do NOT introduce any other content word, even a common or "easy" one (e.g. do not add "maduro/спелый", "rojo", "rápido", "ayer" unless it is in `words`).
- The ONLY words you may add that are not in `words` are tiny grammatical/function words: articles (el/la/un/una), pronouns (yo/tú/él…), prepositions (en/a/de/con…), conjunctions (y/o/que/pero), negation (no), and the basic auxiliary/linking verbs ser, estar, tener, haber, ir, hacer. Nothing else.
- If you cannot build a natural sentence from the available words for one slot, make a simpler sentence using fewer of them — never reach for an outside content word.
- Keep sentences short (3–8 words), everyday, and assessable. Russian often omits distinctions required in Spanish: if an article or an explicit subject pronoun is required for the intended answer, add a short `clarification_ru`. Examples: "Речь о конкретной, уже известной книге." or "Подлежащее можно не называть: форма глагола понятна." Do not add a clarification when it is unnecessary.
- Never make an item depend on guessing whether a noun is definite/indefinite, or whether a pronoun is required. Prefer a simpler sentence when no natural clarification resolves it.
- Vary the sentences; do not repeat the same structure every time.
- `prompt_ru` MUST be a fully grammatical, natural {{native_lang}} sentence a native speaker would actually say. If the available words cannot form a natural, correct {{native_lang}} sentence, build a SIMPLER sentence with fewer words rather than an awkward or broken one. NEVER output ungrammatical or nonsensical {{native_lang}} (e.g. wrong case, missing verb, word salad like "это фонду молодого человека").

LANGUAGE
- `prompt_ru` MUST be written entirely in {{native_lang}}, using ONLY the {{native_lang}} script/alphabet. It MUST NOT contain any {{target_lang}} word, name, or letter — translate every content word into {{native_lang}}. A single {{target_lang}} token leaking into `prompt_ru` makes the item invalid.
- CRITICAL: the entries in `words` are {{target_lang}} lemmas. They belong ONLY in `reference_es`. In `prompt_ru` you MUST use the `translation` field ({{native_lang}}) for each word — NEVER copy the `lemma`. Example of a FORBIDDEN leak: given {"lemma":"gato","translation":"кот"}, writing "gato пьёт воду" is WRONG; the correct `prompt_ru` is "Кот пьёт воду". If you cannot recall the {{native_lang}} word, drop that word and build a simpler sentence — never fall back to the {{target_lang}} lemma.
- `reference_es` MUST be written entirely in {{target_lang}}. Never mix languages in a field.

OUTPUT (STRICT)
- Output ONLY the JSON object, nothing else. No markdown fences, no explanation before or after.
- Shape:
{
  "sentences": [
    {
      "prompt_ru": "<sentence in {{native_lang}} for the learner to translate>",
      "clarification_ru": "<short optional Russian context; empty string if not needed>",
      "reference_es": "<the single correct {{target_lang}} translation>",
      "used_words": ["<lemma from words[] actually used in this sentence>", ...]
    }
  ]
}
- `used_words` MUST contain only lemmas that appear (in any inflected form) in `reference_es` and that came from the input `words`. Omit added function words.
- `reference_es` MUST be a correct, natural translation respecting `allowed_tenses`.
- Produce exactly `sentence_count` items.
