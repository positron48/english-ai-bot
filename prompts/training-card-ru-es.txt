  - Example: "parado" => ACCEPT (must not be rejected by substring overlap).
- Reject nonsense: if the input contains ANY digits (0-9) => reject.
- Otherwise ACCEPT (do NOT reject for uncertainty).
- General acceptance rule: if token contains only letters/diacritics (no digits) and is not in hard reject list, ACCEPT it.
- LOANWORDS, INTERNATIONALISMS, TECHNICAL/SCIENTIFIC TERMS, NEOLOGISMS, AND ENGLISH-LOOKING TOKENS ARE ALWAYS ACCEPTED.

- Default mode is ACCEPTED card. Switch to rejected shape ONLY when formal reject condition is true.

- DECISION FUNCTION (execute exactly, before generating senses):

  5) IF `reject_policy` is true -> output rejected JSON shape and STOP
  6) ELSE -> output accepted JSON (`error=""`, non-empty `senses`, non-empty `transcription`)
