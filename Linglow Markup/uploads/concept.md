# ТЗ на дизайн-прототип Linglow

## 1. Описание продукта

**Linglow** — мобильное приложение для изучения языков.
Пользователь изучает язык через метафору города: каждый изучаемый язык представлен как отдельный город, который постепенно открывается и становится живее по мере занятий.

Первый язык для проработки дизайна — **испанский**.
Город испанского языка называется:

```text
Ciudad Luminaria
```

Главный маскот приложения — **Lumi**, маленький светлячок-проводник.

---

# 2. Основная идея интерфейса

## 2.1 Город

Город — это главный визуальный слой приложения. Он показывает путь пользователя в изучении языка.

Город должен ощущаться как:

* цельное пространство;
* испанский по атмосфере;
* тёплый, светлый, дружелюбный;
* живой и немного сказочный;
* не детский, но уютный.

Через весь город проходит зелёный парк / русло реки, визуально напоминающее парк Турии в Валенсии. Это центральная ось города, которая связывает районы между собой.

---

## 2.2 Районы

Город состоит из районов.
Каждый район — это **этап освоения языка**, а не отдельная бытовая тема.

Районы открываются постепенно.

Базовый набор районов для испанского города:

```text
Puerta de la Chispa
Plaza Clara
Barrio Vivo
Puentes del Relato
Distrito Alto
Campus de Maestría
```

Названия районов должны быть видны прямо на карте.

Районы должны выглядеть как части одного города, а не как отдельные изолированные города. Между ними должны быть мягкие переходы: улицы, парк, мосты, площади, кварталы, зелёные зоны.

---

## 2.3 Содержимое районов

В каждом районе есть 4 области обучения:

```text
Грамматика
Слова
Чтение
Общение
```

Они отображаются под названием района в виде четырёх маленьких иконок.

Рекомендуемая логика иконок:

```text
Грамматика — книга / академический знак
Слова — карточка / словарь / росток
Чтение — открытая книга
Общение — облачко диалога / люди
```

Цвет иконки показывает состояние области:

```text
насыщенный зелёный — хорошо освоено / стабильно
светло-зелёный — в процессе
жёлтый — слабовато, стоит повторить
серый — только начато
иконки нет — эта область ещё не проходилась
```

У закрытых районов:

```text
район приглушённый / серый
есть замок
нет иконок областей
```

# 3. Визуальный стиль

## 3.1 Общий стиль

Стиль интерфейса:

```text
warm
cozy
premium
friendly
clean
illustrative
mobile-first
```

Визуально приложение должно ощущаться как современный образовательный продукт с мягкой геймификацией, а не как детская игра.

---

## 3.2 Палитра

Основная палитра светлой темы:

```text
кремовый / бумажный фон
тёмно-зелёный текст
оливковый зелёный
шалфейный зелёный
мягкий жёлтый / золотой
терракотовые акценты
светло-серый для закрытых зон
```

Состояния прогресса:

```text
зелёный — стабильно
светло-зелёный — развивается
жёлтый — слабое место
серый — начато / нейтрально
приглушённый серый — закрыто
```

---

## 3.3 Испанская атмосфера

Карта города должна использовать испанские архитектурные мотивы:

```text
мадридские площади и дворцовая архитектура
барселонский модернизм / гауди-подобные формы
валенсийский парк Турии и светлая средиземноморская архитектура
севильские башни, арки, тёплый камень
гранада / альгамбра-подобные мотивы
каменные мосты, акведуки, старые кварталы
белые дома, терракотовые крыши, зелёные дворики
```

Архитектурные мотивы должны помогать различать районы, но город должен оставаться единым.

# 4. Маскот Lumi

## 4.1 Внешний вид

Lumi — маленький светлячок.

Визуальные признаки:

```text
круглая зелёно-жёлтая голова
большие чёрные глаза
румяные щёки
две закрученные антенны
прозрачные крылья
листовое зелёное тело
светящийся жёлтый хвост
мягкий добрый характер
```

Lumi должен выглядеть близко к ранее выбранному референсу: милый, простой, читаемый, не перегруженный деталями.

---

## 4.2 Роль в интерфейсе

Lumi используется как:

```text
проводник по городу
помощник в подсказках
персонаж для empty states
персонаж успешного ответа
персонаж при ошибке
помощник в грамматике
помощник в тренировках
помощник в AI-чате
```

Тон Lumi спокойный и дружелюбный.

Примеры фраз:

```text
Продолжим путь?
Сегодня лучше укрепить чтение.
Это слово стоит повторить завтра.
Ты уже увереннее в Plaza Clara.
```

# 7. Экран: Карта города

## Назначение

Карта города показывает структуру изучения языка через районы.

Это главный визуальный экран продукта.

## Header

```text
кнопка назад или меню
Ciudad Luminaria
подзаголовок
streak
```

Пример подзаголовка:

```text
Исследуй город и учи испанский каждый день.
```

## Основная карта

Карта занимает большую часть экрана.

На карте должны быть районы:

```text
Puerta de la Chispa
Plaza Clara
Barrio Vivo
Puentes del Relato
Distrito Alto
Campus de Maestría
```

Под названием открытого района отображаются иконки областей:

```text
грамматика
слова
чтение
общение
```

Цвет каждой иконки показывает состояние области.

Закрытые районы отображаются приглушёнными, серыми, с замком.

## Требования к карте

Карта должна быть:

```text
цельной
плотной
акварельной
с испанской архитектурой
с зелёным парком / руслом реки через весь город
без крупных карточек поверх районов
без маршрута дня
без нижнего блока глобальных сервисных зданий
```

Районы должны быть подписаны простым текстом прямо на карте.

```text

→ прогресс
```

Главная визуальная идея:

```text
Пользователь не проходит курс на 100%.
Он постепенно осваивает живой город языка.
```

Город показывает не финальную точку, а состояние владения языком: что уже стабильно, что развивается, что требует практики и что откроется дальше.
