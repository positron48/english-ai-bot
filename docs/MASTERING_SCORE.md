# Mastering Score (0–100)

Оценка «освоенности» слова по данным тренировок: хранится в `user_word_mastering.mastering_score`, обновляется при создании карточек и после каждой сессии.

## Константы

- **M** = 5 — минимальное число повторений по слову, чтобы доверять оценке.
- **K** = 20 — сколько последних ответов учитывать для «недавней» точности.
- **W** = 0.5 — вес недавней точности в финальной формуле (половинка общая, половинка по последним K).

## Правила

1. **Слово в user_word_knowledge со статусом known** → **score = 100**.
2. **total = 0** (нет событий в review_events по этому слову) → **score = 0**.
3. Иначе:
   - **A_overall** = correct / total (точность за всё время).
   - **A_recent** = recent_correct / max(1, recent_total) (точность по последним K ответам).
   - **Доверие** = min(1, total / M).
   - **A** = (1 − W) × A_overall + W × A_recent.
   - **score** = round(100 × A × доверие).

## Примеры

- 10 неправильно, потом 10 подряд правильно: A_overall = 0.5, A_recent = 1 → A = 0.75 → при доверии 1 score ≈ 75.
- 1 правильный из 1: доверие = 1/5 = 0.2 → score не может быть высоким (ограничение «минимум повторений»).
- 20 из 20 правильно: A = 1, доверие = 1 → score = 100.

## Где обновляется

- **При создании карточек** (добавление слова в тренировки): запись с score = 0 (или 100 для known).
- **После завершения сессии** (веб и бот): пересчёт по всем словам, затронутым в сессии (один батч-запрос, без цикла по словам).

## Выкат

1. Миграция схемы (таблица `user_word_mastering`).
2. Разовый бэкфилл: `make backfill-mastering` (или `./bin/backfill_mastering`).
3. Дальше обновление только по событиям.
