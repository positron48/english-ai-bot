## Исправления сбора жалоб

Серверный `course=es` пропускал только word_training и `grammar_chapter_id LIKE 'es.%'`. Reading ID `free_es_*` не попадали ни в список, ни в summary. Общий фильтр списка/сводки теперь учитывает reading ID и язык текста из БД. Сборщик получает все страницы без серверного course и распределяет их локально, поэтому работает и до релиза исправленного сервера. Неопределённый курс остаётся видимым; legacy API отмечается как неполная выборка с ненулевым кодом завершения.

Кластеризатор разделяет reading по text_id, grammar_chapter/grammar_test — по идентификаторам грамматики, неизвестные типы — по report ID. В detail API добавлен текущий reading-документ из БД отдельно от исторического payload.

`resolve_all_active.py` требует конкретные ID и причину, по умолчанию работает как preview. Исправлены выбор токена EN/ES и даты JSONL. Массового закрытия всех активных жалоб больше нет.
