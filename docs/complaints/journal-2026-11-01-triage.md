## Дополнение: схема ID блоков

По просьбе пользователя устранено несоответствие схемы опубликованным ID. Проверены все 152 главы: диакритические знаки в ID блоков/понятий встречаются в 076 (`ísimo`) и 105 (`qué`). База использует эти строки в ключах SRS и истории ответов, поэтому ID сохранены, миграция прогресса не нужна.

В ES `02-chapter-schema.json` испанские строчные буквы разрешены для block.id, concept_id, concept_refs, theory_block_id и тегов. ID глав/вопросов/вариантов и ссылки на вопросы сохранили ASCII-ограничение. Схема также дополнена уже используемым типом `matching`: обязательные pairs, минимум две пары, непустые left/right. Иначе после устранения ID-ошибки глава 076 всё равно не проходила схему.

AJV с полной проверкой: главы 076 и 105 PASS. Отрицательные проверки: пробел/слеш в ID, matching без pairs и пара с пустым left отклоняются. Прежнее ограничение JSON Schema, описанное выше, устранено; сами ID, контент и runtime-пакеты этим дополнением не менялись. Изменение схемы включено в разрешённый пользователем push.
