# Удаление испанских текстов ниже 7/10

Источник решения — историческая оценка 429 текстов в `scores.csv`. По ней 143 текста получили 4–6/10: 10 с оценкой 4, 64 с оценкой 5 и 69 с оценкой 6.

Перед удалением хеш каждого исходного JSON сравнили с `source_sha256` из отчёта. Один текст с первоначальной оценкой 4/10 — `free_es_a1_provincias_de_galicia_1782924678` — уже заменён рассказом «El paraguas rojo» и оценён повторно на 9/10, поэтому сохранён.

Удалены остальные 142 текста: 9 с оценкой 4, 64 с оценкой 5 и 69 с оценкой 6. По уровням: A0 — 15, A1 — 124, A2 — 2, B1 — 1. Вместе с JSON удалены их отдельные каталоги `assets/reading/<id>` с MP3 и обложками. Из `reading/index.json` удалены все ссылки на них. В каталоге осталось 287 текстов. Список удалённых ID, названий, уровней, баллов и исходных хешей — в `removal-below-7.csv`.

В Linglow с `CONTENT_SOURCE=db` после выката нового образа нужно выполнить импорт каталога `es_ru`. Импорт заменяет испанские строки `reading_texts` и удаляет прогресс чтения для исчезнувших ID. Кластерная команда выполняется оператором на сервере:

```bash
kubectl -n linglow exec deploy/linglow -- /app/import_learning_content --course-code=es_ru --commit
```
