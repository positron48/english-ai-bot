# Проверка соответствия обложек текстам — 2026-10-28

По просьбе пользователя три сабагента **GPT-6.1 Terra** проверили весь текущий каталог EN/ES: 365 текстов, из которых у 286 указаны изображения. Просмотрены все **572** используемых файла hero/thumbnail. У 79 текстов (78 EN, 1 ES) ссылок на изображения нет; это не ошибка отсутствующего файла.

Результат: 237 обложек соответствуют, 40 имеют второстепенные/тематические расхождения и оставлены, **9 существенно расходятся и заменены**. Для каждой новой обложки выпущены отдельные hero и thumbnail — 18 новых WebP. Оригиналы сохранены, в JSON обновлены пути и инструкции для будущей генерации. Тексты, переводы, вопросы, озвучка и токены не менялись.

Все исходные hero и thumbnails просмотрены на подписанных контактных листах, сомнительные случаи дополнительно крупно. Сравнивались полные тексты, а не только заголовки или старые image prompts. Все новые изображения проверены отдельно сабагентами и повторно родительским агентом, включая миниатюры. У семейной сцены дополнительно исправлен первый результат генерации: вместо сумки на бедре нужен именно рюкзак на спине.
