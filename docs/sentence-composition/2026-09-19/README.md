# Генерация общим пулом: 2026-09-19

Это промежуточный этап до сокращения промпта и подбора модели. Финальные настройки, результаты и ограничения: [Gemini 3.8 Flash + low](model-comparison/README.md).

## Поведение

Вместо четырёх независимых пятёрок и четырёх попыток на каждую генерируется
общий пул: для цели 20 запрашивается 30 кандидатов. В запрос входят все основные
и вспомогательные слова. После локальных проверок оставшиеся кандидаты проходят
один LLM-review. Повтор русского задания отсеивается до review, даже если перевод
или контекст отличаются; сравнение с историческими наборами не добавлялось.

При недоборе выполняется один дополнительный запрос: недостающее количество +50%
с округлением вверх. Он получает уже принятые задания и отклонённые кандидаты
с конкретными причинами из локальных проверок и LLM-review. Новые кандидаты снова
проходят обе проверки. Отдельного дописывания контекста и повторов на пустой или
некорректный JSON больше нет. Лимит ответа масштабируется с размером пула.

Обычно это 2–4 запроса; если все кандидаты отсеяны локально, LLM-review пропускается.
Общий HTTP-транспорт по-прежнему может повторять запросы при сетевых сбоях.
Если добор завершился ошибкой, ранее проверенные задания возвращаются для сохранения.

Непустой проверенный результат сохраняется, даже если в нём меньше 20 заданий.
Пустой результат возвращает ErrNoReviewedSentences и не увеличивает счётчик
ошибок общего circuit breaker. Ошибки провайдера/JSON до получения пригодных
заданий остаются ошибками генерации. Запись набора, заданий и счётчиков слов
остаётся одной транзакцией. Миграции не нужны.

## Облачный smoke из локальной машины

Endpoint: Polza `/api/v1/chat/completions`. Модель в запросах и ответах:
`google/gemini-3-flash-preview`. Поле provider в ответах Polza — `openrouter`.
Ключ прочитан из локального `.env`; в артефактах ключей нет. Входной словарь
синтетический (`sentenceTestWords("adversarial")` для ES), не словарь пользователя
из production. Условие принудительного количества фраз с «вы» отключено.

Финальный код и промпты:

| Курс | Принято кодом / цель | HTTP-запросы | Время | Вход / выход, токены | usage.cost Polza |
|---|---:|---:|---:|---:|---:|
| ES | 16/20 | 4 | 42,9 с | 13 815 / 5 490 | 2,751812 ₽ |
| EN | 20/20 | 2 | 20,7 с | 4 210 / 3 490 | 1,480228 ₽ |

ES: первый запрос вернул 30 кандидатов; 19 отсеяны локально, из оставшихся 11
LLM отклонила один, сервер — ещё один из-за неточной цитаты контекста. На доборе
запрошено 17 кандидатов; до review дошло 12, итоговый набор содержит 16 заданий.
Недобор ожидаемо сохраняется по новому контракту, а не превращается в потерю набора.
В предыдущем прогоне ES получилось 19/20 за четыре запроса; старое утверждение
smoke о строго полном наборе упало. Его заменили проверками нового контракта:
непустой результат не больше цели, уникальные русские задания, пригодный контекст,
не больше четырёх HTTP-запросов в этом прогоне. Число принятых заданий публикуется
явно; smoke не доказывает стабильное получение всех 20.

Артефакты: `generated-es.json`, `generated-en.json`, `metrics-es.json`,
`metrics-en.json`. Метрики содержат модели, usage, причины отказов и SHA256 исходников.
Первый эксперимент до усиления уникальности дал ES 20/20 за 4 запроса, но содержал
повторы русских фраз с разными переводами и не считается финальным результатом.

## Ручная проверка и ограничения качества

Сокращение запросов и сохранение частичного набора проверены. LLM-review всё ещё
не является гарантией лингвистического качества. В финальной ES-выборке замечены:

- №6: «Она ищет большого друга» с пояснением о высоком росте — неестественный
  русский текст и недостаточно точное соответствие `grande` этому пояснению.
- №5 и №9: пояснения с альтернативами через «или», хотя промпт просит одну ситуацию.
- №4: пояснение о только что подаренной книге допускает более определённое
  прочтение, чем выбранный `un libro nuevo`.

В EN №4 контекст переключается с «мы» на «я», №13 подменяет дверь воротами,
№20 `closing the house` хуже передаёт запирание на ключ, заданное контекстом.
Это оставшиеся ограничения выбранной модели/проверки, а не автоматически
исправленные задания: сохранены исходные ответы API без ручного редактирования.
Оценку пользовательских ответов этот change не меняет.

## Модель и выпуск

В проверенном `devops-time-host/origin/main` (`e722637`) у Linglow не было
`AI_SENTENCE_MODEL`. Значение `openai/gpt-5.4-nano` задавалось только для
`AI_CONVERSATION_MODEL`. В приложении с коммита `f141e1a6` sentence-модель по
умолчанию уже Gemini 3 Flash. Локально в GitOps ConfigMap Linglow теперь явно
добавлено `AI_SENTENCE_MODEL: "google/gemini-3-flash-preview"`.

Изменения не закоммичены, не отправлены и не развёрнуты. Действующая модель pod
не проверена: Codex не выполняет production kubectl локально. Оператор может
проверить стартовый лог на сервере:

```sh
kubectl -n linglow logs deploy/linglow --since=48h | grep 'sentence model override active'
```

Для повторения smoke:

```sh
RUN_SENTENCE_GENERATION_LLM=1 \
SENTENCE_TEST_MODEL=google/gemini-3-flash-preview \
SENTENCE_TEST_REALISTIC=1 \
SENTENCE_TEST_OUTPUT_DIR=/tmp/sentence-pool-smoke \
go test ./internal/ai -run '^TestSentenceGenerationContextLLM$' -v -count=1 -timeout 10m
```

Для EN добавить `SENTENCE_TEST_COURSE=en_ru SENTENCE_TEST_COUNT=20`, используя
отдельный каталог артефактов. Ключи не передавать аргументами командной строки.
