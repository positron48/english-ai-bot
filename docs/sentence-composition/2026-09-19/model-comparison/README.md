# Промпт, модель и бюджет генерации: 2026-09-19

Выбор по результатам локальных облачных прогонов: **google/gemini-3.8-flash,
reasoning.effort=low**. В приложении и локальном GitOps Linglow заданы
`AI_SENTENCE_MODEL=google/gemini-3.8-flash` и `AI_SENTENCE_REASONING_EFFORT=low`.
Изменения подготовлены для релиза `0.12.204`. Модель работающего production pod
и завершение развёртывания не проверялись.

## Что исправлено до сравнения

- Длинный повторяющийся промпт заменён последовательными правилами составления
  задания, использования словаря и написания контекста. Он теперь явно сообщает
  все запрещённые подстроки контекста, а не отдельные примеры слов с ними.
- Промпт review теперь сообщает фактический контракт цитат: точная подстрока
  clarification_ru, сохранение регистра/ё/пунктуации, минимум 12 символов.
- Исправлена потеря `temperature: 0` из-за `omitempty`: review действительно
  отправляет ноль. Остальные вызовы этого метода задают ненулевую температуру.
- Добавлен отдельный sentence-scoped reasoning.effort, который применяется к
  генерации, review и оценке перевода; общий чат и другие режимы его не наследуют.
- Сохраняется общий пул из 30 кандидатов на цель 20, максимум один адресный добор,
  локальные проверки, независимый запрос review и сохранение непустого частичного
  результата. Успех с первого прохода означает два запроса, а не отказ от проверки.

## Первичное сравнение одинакового ES-словаря

Все модели получили один и тот же компактный промпт и синтетический сложный
словарь. Цель — 20 заданий. В первых четырёх строках review ещё не отправлял
temperature=0 (эти прогоны выполнены до обнаружения ошибки сериализации).

| Модель / настройка | Принято кодом | Запросы | Секунды | Фактическая стоимость Polza |
|---|---:|---:|---:|---:|
| Gemini 3 Flash, старый default review temperature | 20/20 | 2 | 32,3 | 1,57 ₽ |
| Gemini 3.8 Flash, без reasoning override | 20/20 | 2 | 23,0 | 1,75 ₽ |
| GPT-5.4 mini | 16/20 | 4 | 20,3 | 2,54 ₽ |
| Claude Haiku 4.5 | 15/20 | 4 | 59,6 | 7,61 ₽ |
| Gemini 3 Flash, явный review temperature=0 | 20/20 | 4 | 31,3 | 1,74 ₽ |
| DeepSeek V3.2, явный review temperature=0 | 20/20 | 2 | 67,6 | 0,36 ₽ |

**«Принято кодом» не означает отсутствие лингвистических ошибок.** Ручная проверка:

- GPT-5.4 mini: «Я покупаю книгу», контекст «ещё не выбрал ни одной книги»,
  перевод `Compro el libro` — неподтверждённый артикль; встречаются пояснения,
  описывающие знание только говорящего вместо обоих собеседников.
- Gemini 3 Flash после исправления temperature: «Вы покупаете книги» при контексте
  «к одному человеку на ты» и переводе `Compras libros` — противоречие русского
  обращения. Также прошла тавтология «Друзья едят еду».
- DeepSeek: контекст «собеседник передал вам книгу» с `Leo un libro`; ряд заданий
  без личной формы глагола, вопреки текущим требованиям промпта. Дешевизна не делает
  его пригодным кандидатом для замены в этой задаче.
- Haiku не укладывается в выбранный ориентир бюджета 2–3 ₽ на набор уже по API usage.

На втором словаре Gemini 3 Flash без явного temperature вернула некорректный JSON
review (0 заданий, 1,29 ₽); после исправления temperature тот же сценарий дал
20/20 за 2 запроса и 1,31 ₽. Это отдельные стохастические прогоны, а не доказательство,
что изменение temperature само по себе устраняет все ошибки.

## Почему Gemini 3.8 требует явного reasoning

Без override второй словарь стоил 6,27 ₽: review потратил 9 692 reasoning tokens.
Сложный тест обращений стоил 10,17 ₽ и не дал набора: review потратил 11 520
reasoning tokens, завершился с `finish_reason=length` и оборвал JSON.

Polza поддерживает `reasoning.effort` в теле запроса и alias-параметр модели;
проверено по [официальной документации Chat Completions](https://polza.ai/docs/api-reference/chat/completions).
Каталог моделей также получен непосредственно из [публичного API](https://polza.ai/api/v1/models).
Цены top_provider не равны гарантированной цене реально выбранного маршрута:
для сравнения использован **usage.cost_rub / usage.cost из ответов**, а не прогноз
по каталогу. Snapshot каталога находится в `catalog-prices.json`.

## Финальная настройка: Gemini 3.8 Flash + low

| Независимый сценарий | Принято кодом | Запросы | Время | Стоимость |
|---|---:|---:|---:|---:|
| ES: не менее половины заданий с «вы» | 20/20 | 2 | 26,3 с | 1,91 ₽ |
| ES: второй словарь (молоко, кофе, хлеб, машина, магазин) | 20/20 | 2 | 20,0 с | 1,68 ₽ |
| EN: present simple / continuous, 20 заданий | 20/20 | 2 | 21,6 с | 1,68 ₽ |

В первом сценарии low передавался через документированный alias модели
`@reasoning_effort=low`; в двух следующих — через production-код
`reasoning: {"effort":"low"}`. Запросы и model в ответах сохранены в `results.json`.
В этих прогонах usage сообщил 0 reasoning tokens; это наблюдение ответа провайдера,
а не гарантия нулевого reasoning во всех будущих запросах.

Все 60 финальных заданий прочитаны вручную. Грубых ошибок согласования обращения,
явных неправильных переводов и противоречий артиклей, аналогичных указанным выше,
не обнаружено. Некоторые пояснения остаются формальными, а жизненные ситуации —
учебными; идеального литературного качества эти результаты не доказывают.

Дополнительные проверки:

- **12/12** авторских примеров для review: корректные задания и заведомые ошибки
  обращения, артиклей, словаря, противоречивого контекста и естественности.
  Один запрос, 0,43 ₽. Это регрессии наблюдавшихся проблем, не слепой holdout.
- **24/24** основных примера оценки пользовательских ответов: 28 вызовов, 5,22 ₽.
- **14/14** дополнительных примеров оценки с другой лексикой: 19 вызовов, 3,47 ₽.

Ни один прогон не заменён повторным до удачного результата: ошибки и промежуточные
настройки перечислены в `results.json`. Это небольшой инженерный smoke, а не
статистическое доказательство превосходства модели. Для production остаются review,
ограниченный добор и сохранение частичных наборов. Исходный словарь пользователя
не выгружался; browser/production/CI smoke не выполнялся.

## Артефакты и воспроизведение

- `results.json`: все 13 генерационных прогонов, расходы, параметры запросов,
  проверки review и ошибки JSON.
- `*-sentences.json`: исходные задания каждого прогона, без ручных исправлений.
- `gemini38-low-grade*.log`, `gemini38-low-review.log`: результаты проверок оценщика.
- `final-source-sha256.json`: SHA256 финальных исходников и промптов.

Ключ читается из окружения или локального `.env` и в отчёты не включается.

```sh
RUN_SENTENCE_GENERATION_LLM=1 \
SENTENCE_TEST_MODEL=google/gemini-3.8-flash \
SENTENCE_TEST_REASONING_EFFORT=low \
SENTENCE_TEST_REALISTIC=1 \
SENTENCE_TEST_WORD_PROFILE=holdout \
SENTENCE_TEST_OUTPUT_DIR=/tmp/sentence-model-smoke \
go test ./internal/ai -run '^TestSentenceGenerationContextLLM$' -v -count=1 -timeout 10m
```

Для ES с обращениями убрать REALISTIC и WORD_PROFILE. Для EN задать
`SENTENCE_TEST_COURSE=en_ru SENTENCE_TEST_COUNT=20` и отдельный каталог результатов.
Чтобы сравнить provider default, явно задать `SENTENCE_TEST_REASONING_EFFORT=`.

```sh
RUN_SENTENCE_REVIEW_LLM=1 SENTENCE_TEST_MODEL=google/gemini-3.8-flash \
SENTENCE_TEST_REASONING_EFFORT=low \
go test ./internal/ai -run '^TestSentenceReviewRegressionLLM$' -v -count=1 -timeout 10m

RUN_SENTENCE_REGRESSION_LLM=1 SENTENCE_TEST_MODELS=google/gemini-3.8-flash \
SENTENCE_TEST_REASONING_EFFORT=low \
go test ./internal/ai -run '^TestSentenceRegressionLLM$' -v -count=1 -timeout 10m
```

Для дополнительной проверки оценщика добавить `SENTENCE_TEST_HOLDOUT=1`.
