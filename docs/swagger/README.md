# Swagger API Documentation

## Генерация документации

Для генерации Swagger документации выполните:

```bash
make swagger
```

Или напрямую:

```bash
go run github.com/swaggo/swag/cmd/swag@latest init -g internal/web/router.go -o docs/swagger --parseDependency --parseInternal
```

## Доступ к документации

После запуска сервера документация будет доступна по адресу:

- **Swagger UI**: http://localhost:8184/swagger/
- **Swagger JSON**: http://localhost:8184/swagger/doc.json

## Структура документации

Документация автоматически генерируется из аннотаций в коде:

- Общая информация о API находится в `internal/web/router.go` (в начале файла)
- Аннотации для каждого эндпоинта находятся перед соответствующими функциями-обработчиками

## Обновление документации

После изменения аннотаций или добавления новых эндпоинтов необходимо перегенерировать документацию:

```bash
make swagger
```

## Теги API

API разделен на следующие группы:

- **Auth** - Методы аутентификации (Telegram WebApp и OTP)
- **Dashboard** - Главная панель пользователя
- **Vocab** - Управление словарным запасом
- **Training** - Система тренировок и обучения
- **Chat** - AI чат для помощи в изучении языка
- **Admin** - Административные функции
- **Learning Placement** - Самостоятельная диагностика EN/ES: создание и восстановление сессии, ответы, завершение, история. Аннотации и вспомогательные схемы находятся в `internal/web/placement_swagger.go`; старые placement API помечены `deprecated` и документированы как `410 placement_replaced`.

## Аутентификация

Большинство эндпоинтов требуют аутентификации через cookie сессию. В Swagger UI это можно протестировать, сначала выполнив запрос на `/auth/telegram` или `/auth/otp`, который установит cookie сессии.
