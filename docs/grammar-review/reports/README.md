# Отчёты полного прохода

Здесь сохраняются JSON-отчёты по пути `report`, который выдаёт
`python3 scripts/grammar-review.py inventory`.

Имя — стабильный хеш пути исходника. Шаблон:
`python3 scripts/grammar-review.py template --source <путь-из-инвентаризации>`.

Отчётов вычитки пока нет. Старые статусы ES и точечные исправления не переносятся как `done`.
Правила заполнения и возобновления — в [процессе вычитки](../README.md).
