# ES verb forms: системная правка контрфактических переводов

Дата исправления и проверки: 2026-09-06.

## Объём

- Проверены все уже отредактированные файлы форм глаголов с конструкцией
  `De haberlo sabido, ...`.
- Исправлено 1596 русских переводов в 266 леммах: по шесть карточек
  `condicional-perfecto` в каждом файле.
- Фактическое «Зная это заранее, ...» заменено на явное контрфактическое
  «Если бы ... знал/знали об этом заранее, ... бы ...».
- Source-файлы, встроенные копии и fingerprints всех 266 reports синхронизированы.
  Статусы редакторской и независимой проверки сохранены.

Работа выполнена четырьмя параллельными исполнителями на непересекающихся
шардах: 67, 67, 66 и 66 файлов. Каждый исполнитель записывал результат в свой
checkpoint; общие файлы кампании и проверки изменял только координатор.

## Дополнительные исправления

При полном просмотре затронутых переводов обнаружены и исправлены ещё семь
дефектов:

- шесть неестественных форм в `deber`, включая `долженл`, `должныли` и двойное
  `бы`; они заменены на естественные конструкции со `следовало бы`;
- в форме первого лица `pedir` исправлено `попросил помощь` на
  `попросил о помощи`.
