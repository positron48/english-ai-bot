## Основные исправления

- Формы `hablar`, `hacer` и `hallar` сверены с локальной базой Jehle. Формы
  `haber` сверены с отдельной проектной парадигмой
  `resources/verbs/jehle_supplement_aux_haber.csv`, поскольку исходная база
  Jehle не содержит эту лемму.
- Исправлено 86 неверных `surface_form`: 42 в `haber`, 18 в `hablar`, 18 в
  `hacer`, 8 в `hallar`. В частности, у `haber` восстановлены составные времена
  с `habido` и оба будущих времени subjuntivo; у `hacer` восстановлены
  `hiciere`, `hubiera hecho` и `hubiere hecho`.
- В исходных файлах обнаружено 53 карточки с повторяющимися вариантами. Теперь
  в каждой карточке четыре уникальные формы того же scope, правильная встречается
  ровно один раз.
- Все задания `haber` переведены в однозначный формат проверки парадигмы по
  местоимению, времени и наклонению. Это устраняет ошибочные переводы `haber` как
  смыслового «иметь» и не создаёт искусственные контексты для форм вроде `he
  habido`.
- Для `hablar`, `hacer` и `hallar` контексты разделены по устойчивым значениям:
  обсуждать тему, выполнять работу и находить объект. Русские переводы согласованы
  с лицом, числом и временем.
