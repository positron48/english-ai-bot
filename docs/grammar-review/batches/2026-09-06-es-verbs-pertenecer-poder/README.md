  карточке четыре уникальные формы того же scope, правильная встречается ровно
  один раз.
- Контексты последовательно используют `pertenecer a` для членства в
  организации, переходный `pesar` для взвешивания, `picar` в значении нарезки
  продуктов и `poder` с инфинитивом.
