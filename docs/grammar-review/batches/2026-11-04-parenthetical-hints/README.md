Завершён разрешённый пользователем редакционный аудит **4647 вопросов в 428 исходных файлах EN/ES**. Каждый выбранный вопрос прочитан с условием, вариантами, ключом, объяснением и контекстом теории. При необходимости восстановлена недостающая лексема, заданы время/лицо или ограничены допустимые варианты, чтобы после удаления подсказки оставался проверяемый ответ. Обычная исходная форма для спряжения и грамматический контекст сохранены.
